## 2026-09-18 · 初始化

- 建立数据资产骨架：`SCHEMA.md`（唯一数据契约）+ 7 个交付文件（空表头）+ `brands/` 目录。
- 明确三条硬约束：不假精确（no fake precision）、merchant_claim ≠ nutrition_fact、来源可追溯。
- 本轮**不修改 App UI / 不增加产品功能**，全部精力投入品牌发现、菜单扫库、营养检索、来源核验、结构化保存。

### 研究方法约定
- 营养数据分层：A 官方 → B 有方法的第三方实测 → C component estimate → D vision/semantic。
- 菜单事实（SKU 存在性/分类/规格/套餐组成）优先来自官方菜单 / 美团 / 饿了么。
- 小红书用于：缺失营养数据的实测线索 + 减脂用户真实点单组合。仅"好吃/减脂"式笔记不作证据。
- 需要登录的平台：仅在浏览器已具备访问条件时正常浏览，不绕过登录/权限/安全限制。

### 待人工确认的假设（开放清单）
- [ ] 各品牌"当前外卖菜单正餐 SKU 总数"为估计值，需以实际扫库结果回填。
- [ ] 便利店（全家/罗森）SKU 极多且区域差异大，第一轮是否只收"减脂高频"子集待定。

## 2026-09-18 · 肯德基中国 KFC (brand_slug=kfc-cn, category=B)

- 写入 `brands/kfc-cn.json`：144 条 SKU（132 single_item + 12 preset_combo）+ 144 条 source，13 个 menu_category。
- confidence：**A 6 / B 0 / C 35 / D 2 / U 101**。research_status：complete 35 / needs_estimation 22 / nutrition_missing 2 / menu_only 85。
- estimated_total_food_skus = **165**（区间 150–180，不含饮料；含套餐的全菜单行约 230–280。受时段门控影响，宅急送任一时刻实际可售约 110–140）。

### 关键限制：官方渠道全线阻断（未绕过）
- `order.kfc.com.cn` 是**唯一在售官方 web 订餐端**（Taro SPA，build 20260128_152）。抓其 2.0MB bundle 后 grep `nutrition|nutrient|calorie|kcal|energy|营养|热量|蛋白质|成分` → **0 命中**，官方 web 订餐端完全不含营养字段。
- 其 `/preorder-portal/api/v2/menu/*` 需签名头 `kbcts`/`kbck`/`kbsv` + 极验指纹（fp.hwwt8.com）+ login.kfc.com.cn 登录态；匿名一律返回 `code=120000002『换取5层结构失败』`。**判定 blocked，未尝试绕过签名或登录。**
- `kfc.com.cn` 为 13KB 静态营销页（无 script、无菜单、无营养链接）；`/kfccda/*` 全 404。
- 百胜中国官网仅政策叙述，自述口径为 KPRO『在产品菜单中试行卡路里信息标注』→ **kcal-only、试点、单一子品牌**；可持续发展报告 PDF（2017–2025）不含营养表。
- 美团 / 饿了么为 SPA 壳（需定位+登录）；小红书登录墙。

### 结论：本品牌**无品牌官方 A 级营养数据**，A 级溯源改由政府数据库承担
- 唯一 A 级来源 = **中国食物成分表**（`nlc.chinanutri.cn/fq/`，中国营养学会 + 中国CDC营养与健康所），速食食品›快餐食品类下**恰有 10 条肯德基条目（id 1249–1258）**，per-100g，含能量(kJ)+蛋白+脂肪+碳水+**钠**+胆固醇，实验室分析值。已逐条抓详情页核验。
  - ⚠️ **LICENSE 风险（需人工决策）**：平台明示『未经中国疾病预防控制中心营养与健康所允许，任何单位和个人不得用于商业目的』。若本库用于商业 App，须先取得授权。已在每条 CDC source 的 notes 与品牌级 `nutrition_data_availability` 中标注。
  - ⚠️ 10 条均为**历史 SKU**（含已下架的 鸡柳汉堡 / 香芋甜心 / 鸡肉汉堡），且**无 per-份克重**，故 A 级记录一律以 **per 100克** 为 serving 基准，不臆造份量。
- C 级来源 = fatsecret.cn『肯德基』桶：54 条 URL / 53 个去重产品（47 大陆、5 港台、1 存疑），含 kcal+脂肪+碳水+蛋白，**无钠/纤维/糖**，众包、无方法披露、无菜单日期 → 不满足 B 级『明确方法』要求，定 **C**，point 值一律附 ±12% 区间。
  - 已剔除港台条目（卡啦脆雞 / 原味蛋塔 / 紅藜燕麥嫩雞粥 / 義式香草紙包雞 / 薯條），避免跨市场混入。
- **B 级 = 0**：本轮未发现任何满足『称重/拆解/给出计算过程』要求的第三方实测来源。这是全库性的缺口，不只 KFC。
- D 级 = 2（劲脆超霸堡、红豆派）：来自 smzdm 转载的小红书减脂帖，页面自述**『内容由AI生成』**、无方法 → 仅 kcal、已 ±15% 展开为 range，不作事实。红豆派在 fatsecret 的宏量字段页面上全为 `0克`（无效），故**只留能量、宏量留空，不以 0 冒充实测**。

### 交叉验证（本品牌最有价值的发现）
- fatsecret 多条与中国食物成分表**数值完全一致** → 判定同源转引：
  - 新奥尔良烤翅 240 vs CDC 239 kcal，且 P22.1/F13.8/C6.8 **三项逐一相同**；
  - 薯条 P4.3/F15.5/C40.5 **三项完全相同**，能量差 3.4% 纯属 1289kJ 换算修约；
  - 老北京鸡肉卷↔CDC『鸡肉卷』257 vs 256 kcal。
- 但**并非全部同源**，实质冲突已一律记 `conflicting_sources` + `best_current_estimate`，**不擅自取舍**：
  - **劲爆鸡米花：CDC 304 vs fatsecret 239 kcal/100g（差 27%）**，蛋白差 36%、脂肪差 42% → confidence 由 A **降为 C**，vt=estimated_range，区间 239–304。
  - 香辣鸡翅：CDC per100g（**可食部 67%**）337 kcal vs fatsecret 1个(25g) 106 kcal（折算 424/100g）→ 根本分歧在**带骨基准**，25g 是全重还是可食部未确认 → 降为 range。
  - 吮指原味鸡：**fatsecret 同站两条自相矛盾**（1块87g=242 kcal 折算 278/100g vs 100克条目=161 kcal，能量差 73%）→ range 161–242。
  - 葡式蛋挞：per-个 196 vs per-100g 393（常见 60–65g/只应为 236–255）→ range 196–255。
  - 香甜玉米杯：CDC 125 kcal/100g vs 第三方『一杯约70大卡』→ 分歧本质是**份量非配方**（反推杯重约 56g）→ range 70–125。
- 带骨品的**可食部**是本品牌系统性陷阱：CDC 明确标注 辣鸡翅 67% / 新奥尔良鸡翅 70%，fatsecret 从不标注 → 任何跨源换算都必须先对齐基准。

### merchant_claim ≠ nutrition_fact（本品牌命中较多）
- 12 条 SKU 带营销标签，全部**只进 `merchant_claims`**，并在 `source_notes` 写入显式 `MERCHANT_CLAIM 处理：…未用于推导、调整或验证任何营养数值`：
  - 帕尼尼**轻盈**版（轻盈/低负担）、绿豆薏仁**轻养**粥（轻养）、雪菜笋丁鸡肉粥（轻负担）、九龙金玉**轻乳**茶（轻乳）、KPRO 4 条（轻食/能量碗）、滋滋YES烤鸡腿堡（『脂肪低30%』为第三方/营销口径）、汁汁**和牛**堡（『和牛』为品名用语）。
  - 特别记：帕尼尼轻盈版 vs 标准版**配方差异未经官方营养表公开，二者不可互相推算**。

## 2026-09-18 · Phase 1 Brand Landscape 完成 + 第一轮 Core Brands 定案

- 三路并行检索（A 类专业轻食 / B 类主流连锁 / C-D 类场景与便利店），查询集用真实用户语言（减脂外卖/打工人减脂外卖/减脂期麦当劳/减脂期麻辣烫/便利店减脂早餐…），结果见 `brand_landscape.csv`（30 品牌）。
- 关键发现：
  1. **"排行榜"内容多为 SEO 软文农场**（同一批品牌以标题 tag 批量复用）→ 只作"品牌存活信号"，不作偏好证据。
  2. **真实语料里 A 类存在感弱于软文**：用户自述高频点是沙县（鸡腿去皮+饭减半）、清汤麻辣烫、麦当劳、便利店鸡胸肉。
  3. **官方营养标注 ≠ 可信**：上海消保委测评 60 款轻食，标称 275 实测最高 1544 kcal（5.6 倍）；沙野/FitBee 曾被点名。→ 本库规则：官方标称只给 A 级*来源*；存在可信实测冲突时一律降为 range 并记 conflicting_sources。
  4. 品类从冷沙拉转向**中式热轻食**（轻食拌饭/杂粮饭/热烹）。
  5. **便利店是唯一 nutrition_data_availability=高 的渠道**（包装营养成分表）→ 作为全库校准锚点。
- **第一轮 Core Brands（10）**：麦当劳、肯德基、老乡鸡、Subway、塔斯汀、米村拌饭、超级碗FOODBOWL、沙野轻食、全家、罗森。
  理由（连锁覆盖 × 外卖普及 × 减脂讨论度 × 菜单标准化 × 数据可得 × demo 价值）：麦当劳唯一自带官方计算器；KFC 门店最多但无官方数据=App 价值最大；老乡鸡有 191 道菜官方 4+1；Subway 是组件模型范例；塔斯汀/米村是新一代中式高频；超级碗/沙野代表 A 类且沙野是标称vs实测冲突试金石；全家/罗森是包装标签校准锚点。
  沙县小吃因标准化过低进 C 类 generic template + Phase5 选择库；星巴克/吉野家/永和大王/Tims/袁记云饺 进 Phase5 选择库，本轮不做 full-menu。

## 2026-09-18 · 跨品牌发现

- **B 级实测来源全库稀缺（仅 46 条）**：米村（营养师拆解）、超级碗（门店实拍）、全家/罗森（标签转录+净含量）。建议组织一次自有称重（带骨可食部/薯条鸡米花克重/蛋挞单只/玉米杯杯重/酱料挤量）。
